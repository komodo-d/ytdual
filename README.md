# 🎬 YouTube Dual Sync Player

Aplicación web para cargar **dos videos de YouTube** y reproducirlos de forma sincronizada.

## 🚀 Funcionalidades
- Carga de dos videos por URL (`youtube.com/watch?v=`, `youtu.be/`, `embed` o ID).
- Volumen independiente (A=100% por defecto, B=20%).
- Controles globales: Reproducir, Pausar y Detener ambos.
- Diseño responsivo con **Bootstrap 5**.

## ▶️ Uso
1. Abre `index.html` en tu navegador.
2. Pega dos URLs, presiona **Cargar** en cada video.
3. Presiona **Reproducir ambos**.
